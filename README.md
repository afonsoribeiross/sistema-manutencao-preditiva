# Sistema de Manutenção Preditiva Industrial

Sistema de monitoramento preditivo para motores elétricos industriais desenvolvido em Python. 
Monitora temperatura, vibração e pressão em tempo real, classificando automaticamente o estado 
da máquina em Normal, Alerta ou Crítico com base em limites configuráveis.

## 🔗 Acesse o sistema online
[clique aqui para acessar](https://sistema-manutencao-preditiva.streamlit.app/)

## 📊 Funcionalidades
- Dashboard com inputs de sensores
- Classificação automática: 🟢 Normal / 🟡 Alerta / 🔴 Crítico
- Indicadores visuais estilo painel industrial (gauges)
- Alerta geral do estado da máquina
- Limites de operação configuráveis
- Histórico de leituras
- Grafico de evolução
- Alertas por email

## 🛠️ Tecnologias
- Python
- Streamlit
- Matplotlib
- NumPy
- Pandas
- python-dotenv
